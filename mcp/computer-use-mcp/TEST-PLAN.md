## 0. 测试约定

- **环境**：Windows 10/11，真实鼠标键盘会被操作；
- **安全**：功能测试只操作测试自建的窗口（WinForms），所有按键/按钮操作一律 `try/finally` 释放，防止卡键；
- **测试窗口**：由测试自身创建（PowerShell WinForms，标题唯一 tag），测试结束自动关闭，不留残余进程；
- **判定**：每项标记 `✅ 通过 / ❌ 失败`，失败需记录原因并修复后复测，直到全绿。

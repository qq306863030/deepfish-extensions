# 网页提醒工具

## 功能介绍

在浏览器中打开一个全屏居中、带有高级 CSS 渐变动画的提示页面，用于展示指定的提示消息。

> ⚠️ **注意：仅当用户明确提出"网页提醒"、"用浏览器弹窗"、"打开网页提示"、"网页提醒工具"等明确涉及浏览器/网页展示的请求时才调用此工具。** 不要将此工具用于普通的文字提醒或通知，仅限需要浏览器弹窗展示的场景。

## 工具清单

| 函数名 | 描述 |
|--------|------|
| `showNotify` | 传入提示文本，在浏览器中打开全屏居中渐变动画提示页面 |

## 快速开始

### 安装 Deepfish

```bash
npm install -g deepfish-ai
```

### 添加工具

```bash
npm install -g @deepfish-ai/deepfish-reminder
```

### 使用示例

添加完成后，用户必须在对话中**明确提到"网页提醒/浏览器弹窗"**，AI 才会调用此工具：

```bash
ai "每天7点使用网页提醒工具提醒我下班该打卡了！"
ai "今天下午两点，打开一个浏览器网页提示，内容是要开会了！"
ai "每天12点使用网页提醒工具显示：中午记得吃饭哦"
```

只有当用户明确提出"网页提醒"、"浏览器弹窗"、"打开网页提示"等涉及浏览器展示的请求时，AI 才会调用 `showNotify` 工具函数，在浏览器中打开带有炫酷渐变动画的提示页面。

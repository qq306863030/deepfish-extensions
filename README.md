# DeepFish Extensions

> 因版本升级，目前可用工具：
>
> - **[deepfish-ssh-remote-control](./tools/deepfish-ssh-remote-control/)** — SSH 远程控制工具
> - **[deepfish-reminder](./tools/deepfish-reminder/)** — 网页提醒工具（自动打开浏览器弹出提示页面）
> - **[deepseek-vision-mcp](./mcp/deepseek-vision-mcp/)** — 基于 OpenAI 兼容接口的视觉图像识别 MCP Server（支持本地图片、网络图片 URL、base64 文件）
> - **[ssh-remote-control-mcp](./mcp/ssh-remote-control-mcp/)** — SSH 远程控制 MCP Server（连接管理、远程命令执行、文件上传/下载，内置 Web 管理页面）

其他工具正在逐步适配中，敬请期待。
